# [A4] HEADにcheckpointが無ければ `git push` を許可

## 何を変えるか
HEAD に checkpoint が無ければ `git push` を許可する。merge / cherry-pick の既存例外を push にも広げる。

## 現状（コード根拠）
`shouldBlockGitPush` は無条件ブロック。例外は `interleavingAllowedWithoutCheckpoints`（HEAD が checkpoint でなければ merge / cherry-pick を許可）だけ。

## 実装案
`tool_call` で blocked が `push` のときも `getHeadSubject` を見て、`wip(checkpoint):` で始まらなければ通す。判定は既存関数を流用。

- リスク: ほぼ無し。未コミットの変更は push に含まれない。
