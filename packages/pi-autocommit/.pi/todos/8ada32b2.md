# [C4] `extraTypes` でConventional Commitsのtypeを拡張

## 何を変えるか
`extraTypes` で Conventional Commits の type を増やす（`deps`, `i18n` など）。

## 現状（コード根拠）
`src/commit-types.ts` の `COMMIT_TYPES` が単一の定義元で、プロンプトの type 一覧と heuristic の両方がここから派生。

## 実装案
`loadConfig` で `extraTypes?: Record<string,string>` を読み、`typeReferenceBlock()` にマージ。`determineType` は既存 type しか返さないので影響なし。

## 工数・リスク
60分
- リスク: `CommitType` の union 型を広げる場合は型変更が波及する。
