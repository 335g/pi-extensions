# [F4] commit pickerにdiffプレビュー

## 何を変えるか
commit picker に選択コミットの diff / stat プレビューを出す。

## 現状（コード根拠）
`CommitPicker` はコミット行のリストのみ（`src/commit-picker.ts`）。表示は subject / origin / リモート先端マーカーだけ。

## 実装案
カーソル移動時に `getCommitSummary` + `git show --stat` を非同期取得して右ペインに描画。`PickerStore` にメソッド追加。

## 工数・リスク

- リスク: 非同期描画でちらつく。大きなコミットでレイアウトが崩れる。
