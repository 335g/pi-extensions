# [B5] `singleCommit` 常に1コミット

## 何を変えるか
`singleCommit: true` で常に1コミットにまとめる。分割せず、LLM はメッセージ生成だけ。

## 現状（コード根拠）
`fallbackSingleCommit`（`src/reorganiser-helpers.ts`）が既にあり、LLM失敗時のみ使われる。

## 実装案
`proposeCommitGroups` を呼ばずに `fallbackSingleCommit` を直呼びする分岐を `organizeCheckpointCommits` と `assembleAndCommit` に足す。
