# [C1] トレーラー・テンプレート設定

## 何を変えるか
コミットメッセージのフッター（trailer）とテンプレートを設定できるようにする。`trailers: ["Refs: #12"]`、`template`。

## 現状（コード根拠）
メッセージは LLM か heuristic の出力そのまま。`GitOperations.commit(message)` に後処理は無い（`src/git-operations.ts`）。

## 実装案
`commitGroups` / `fallbackSingleCommit` の `store.commit()` 直前に、config の trailers を末尾へ付与する小さなヘルパーを1つ置く。`BREAKING CHANGE` 行との順序だけ決める。

## 工数・リスク
2時間
- リスク: メッセージ全文を比較している既存テストの更新。
