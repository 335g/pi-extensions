# [D5] 1ターンの変更量上限でスキップ

## 何を変えるか
1ターンで変更が大きすぎる場合に checkpoint をスキップして通知する。

## 現状（コード根拠）
上限判定は `agent_end` の staged diff サイズのみ（`MAX_CHUNKED_DIFF_BYTES`）。`turn_end` に上限は無い。

## 実装案
`turn_end` で working tree 全体の diff サイズを測る軽量コマンド（`git diff --stat | tail -1` 等）を追加し、上限超過ならスキップ + 通知。

## 工数・リスク
1.5時間
- リスク: 誤判定で正当な変更が checkpoint されない。D2 と統合するのが自然。
