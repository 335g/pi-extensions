# [E3] `/autocommit-eject` で手動rebaseに引き渡す

## 何を変えるか
`/autocommit-eject`。checkpoint を残したまま手動の `git rebase -i` に引き渡す。

## 現状（コード根拠）
手動整理は `/autocommit-organise`（LLM）のみ。interactive rebase を起動する経路は無い（むしろガードでブロック対象）。

## 実装案
pi から対話プロセスは起動できないので、`resetSoft` で staged に戻し「あとは手動でコミットしてください」と案内する形（実質 E4）に縮退する可能性が高い。rebase todo ファイル生成までは可能。

## 工数・リスク
半日
- リスク: pi の制約上、対話 rebase の起動は無理筋。E4 と統合して小さくする判断も。
