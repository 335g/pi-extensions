# [A3] コミットガードの個別スイッチ（commit/push/merge/resetHard）

## 何を変えるか
ガードを種類別に切る。`guard: { commit, push, merge, resetHard }` で個別に無効化できる。

## 現状（コード根拠）
`src/commit-policy.ts` の `shouldBlockGitCommit` / `shouldBlockGitPush` / `shouldBlockGitHardReset` / `blockedInterleavingVerb` は独立した純関数だが、`src/index.ts` の `tool_call` で無条件に呼ばれる。config にキーは無い（`KNOWN_KEYS`）。

## 実装案
`PiAutocommitConfig` に `guard?: Partial<Record<"commit"|"push"|"merge"|"resetHard", boolean>>` を追加。`loadConfig` で正規化し、`tool_call` で該当フラグが false ならその判定を飛ばす。既定は全部 true。
