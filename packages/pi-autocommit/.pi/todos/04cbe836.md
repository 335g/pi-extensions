# [E2] 破壊操作前の自動バックアップタグ

## 何を変えるか
`reorganiseSelectedRange` の `hardReset` 前に自動でバックアップタグを打つ。

## 現状（コード根拠）
slow path は `hardReset(beforeSHA)` → 失敗時 `hardReset(originalHead)` で復元するが、プロセスが落ちると reflog 頼り（`src/commit-organizer.ts`）。

## 実装案
`hardReset` 直前に `git tag pi-autocommit/backup-<epoch>` を打ち、成功したら削除（失敗時は残す）。

## 工数・リスク
60分
- リスク: タグが溜まる。成功時の削除を確実にする。
