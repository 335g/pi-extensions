# [D1] `exclude` / `include` globs でステージ対象を制御

## 何を変えるか
`exclude` / `include` globs を追加し、checkpoint が拾うファイルを選ぶ。`git add -A` の全取り込みを止める。

## 現状（コード根拠）
`runCheckpointCommit` は `stageAll()` = `git add -A`（`src/pipeline.ts` / `src/git-operations.ts`）。除外は `ignoreSubmodules` の専用実装のみ。`picomatch` は既に依存（`scope-resolver.ts`）。

## 実装案
ステージ後に name-status を読み、exclude に該当するパスを `unstageFiles()` する共通ヘルパーを1つ作り、checkpoint と整理の直前で通す。

## 工数・リスク
2時間
- リスク: 除外したファイルの取りこぼしに気付かない。除外時に通知が必要。
