# [B3] `split: "paths"` LLMなしの決定的分割

## 何を変えるか
`split: "llm" | "paths"` を追加。`paths` では LLM を使わず path から決定的にコミット分割する。

## 現状（コード根拠）
`completeCommitGroups` は LLM 専用。コードコメントにも "Group count is decided by the LLM (no heuristic for groups)" と明記（`src/commit-prompt.ts`）。決定的なのは単一コミット時の type 判定（`src/commit-message.ts` の `determineType`）だけ。

## 実装案
`split` 分岐を `organizeCheckpointCommits` / `assembleAndCommit` / `reorganiseSelectedRange` の `proposeCommitGroups` 呼び出し前に入れ、`paths` 時は name-status を scope/type でグルーピングして `CommitGroup[]` を作る。
