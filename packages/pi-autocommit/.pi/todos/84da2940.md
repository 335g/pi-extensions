# [C2] 整理コミットだけ GPG 署名する `signCommits`

## 何を変えるか
整理コミットだけ GPG 署名する `signCommits`。checkpoint は署名しないまま。

## 現状（コード根拠）
`commit()` が `-c commit.gpgsign=false` を固定で渡す（`src/git-operations.ts` 194行付近）。署名を有効にする経路が無い。

## 実装案
`commit(message, options?: { sign?: boolean })` にし、`sign` 時は `-c commit.gpgsign=true -S` を付ける。整理コミット側だけ config を見て渡す。

## 工数・リスク
60分
- リスク: gpg 未設定環境ではコミットが失敗する。署名なしで再試行するフォールバックが要る。
