# [I3] ガードのallowlist（外部ツール併用）

## 何を変えるか
ガードの allowlist。特定コマンド（lazygit 経由など）を許可する。

## 現状（コード根拠）
ガードは `git commit` / `push` / `reset --hard` / `merge` / `cherry-pick` / `rebase` を文字列パターンで検出してブロック（`src/commit-policy.ts`）。例外は squash merge 等の固定ルールのみ。

## 実装案
`guardAllow: string[]`（正規表現）を追加し、マッチしたコマンドはブロックしない。

## 工数・リスク
1.5時間
- リスク: 誤った許可は履歴破壊に直結する。既定は空。
