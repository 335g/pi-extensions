# [D4] secretスキャン（opt-in）でコミットをブロック

## 何を変えるか
`.env`、`*_key*`、AWS風文字列などを検出してコミットを止める secret スキャン（opt-in）。

## 現状（コード根拠）
一切無い。`git add -A` は `.gitignore` 済みの `.env` を拾わないが、新規ファイルや誤コミットは防げない。

## 実装案
checkpoint と整理のコミット直前に name-status と diff の先頭 N KB を走査する純関数を追加し、config `denySecrets: true` で有効化。

## 工数・リスク
半日
- リスク: 誤検知でコミットが止まり作業が中断する。除外設定が要る。
