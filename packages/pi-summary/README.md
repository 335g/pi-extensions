# pi-summary

Pi 拡張。現在のセッションの**ユーザーと AI の発話だけ**を抜き出して表示する。tool call、tool 実行結果、system メッセージは出さない。`/summary` 1 コマンドで、表示したまま要約を差し込む。

| キー | 動作 | LLM |
|---|---|---|
| `l` | 選択コメントを箇条書きに要約し、その直後に差し込む | 1 回 |
| `L` | まだ要約していないコメントをまとめて要約 | 未要約の数 |
| `i` | 選択コメントの**直後**の作業だけを箇条書きに要約し、直後に差し込む | 1 回 |
| `I` | まだ要約していない作業をまとめて要約 | 未要約の数 |
| `m` | セッション全体の要約（目的 / 決まったこと / 未解決 / 次にやること） | 1 回 |
| `n` | 引き継ぎモードを開く（引き継ぎ書 + 保留リスト + カバレッジバー） | 1 回 |
| `a` | 選択中の保留項目を採用（再要約して引き継ぎ書へ） | 1 回 |
| `d` | 選択中の保留項目を却下 | なし |
| `e` | 引き継ぎ書をエディタで直接編集 | なし |
| `s` | 全体要約 / 引き継ぎから会話へ戻る | なし |
| `b` | 本文の表示 / 非表示 | なし |
| `h` | 要約の表示 / 非表示 | なし |
| `w` | 作業の表示 / 非表示 | なし |
| `?` | キーバインドの一覧をポップアップで出す（何かキーで戻る） | なし |

同じコメント・同じ作業は 2 回呼ばない（パネルを閉じても、セッションを再開しても）。

要約はセッションの現在のモデル (`ctx.model`) を使う。

## インストール

```bash
pi install @335g/pi-summary
```

リポジトリから直接入れる場合:

```bash
pi install git:github.com/335g/pi-extensions
```

反映は `/reload`。

## 使い方

セッション中に `/summary` を打つ。開いたパネルのまま操作する。

- ユーザーの発話は右寄せ、AI は左寄せの枠で出る
- 会話の選択: `j` / `k`、`↑` / `↓`（実行直後は先頭を選択。選択中は太枠・背景色・`▶`）
- ページ移動: `PgUp` / `PgDn`、`Ctrl-f` / `Ctrl-b`（選択もページ単位で進む）
- 選択中の枠をコピー: `c`
- 選択中の会話から分岐: `t`（`/tree` でその会話を選ぶのと同じ）
- 要約: `l` / `L`（コメント）、`i` / `I`（直後の作業）。箇条書きで、元のコメントの枠の内側に区切り線を挟んで表示する。実行はバックグラウンドで、`Esc` で閉じても続き、完了すると通知が出る
- 全件要約をコマンドで: `/summary-comments`（未要約の全コメント）、`/summary-works`（未要約の全作業）、`/summary-overall`（セッション全体）。パネルを開かずにバックグラウンドで実行する
- キー一覧: `?` で中央にポップアップ（パネルの上に重なるので、下のコメントは消えない）。何かキーを押すと戻る
- 表示の切替: `b` 本文、`h` 要約、`w` 作業を別々に切り替える。最後の 1 種は消せない（全部消える操作は無視）。本文を隠したカードは要約と作業だけを出す
- 要約はセッションに保存する（`pi.appendEntry`）。パネルを閉じても、セッションを再開しても、要約し直さずにそのまま出る
- 全画面: 既定で全画面（最下部 1 行は pi のフッタを残す）。`z` でチャットの下の下部パネル（本文 60%）と切り替え
- 閉じる: `Enter` / `Esc` / `q`（要約中でもすぐ閉じる。`z` も要約中に効く）
- 非 TUI モード (`--mode rpc` など) では標準出力に Markdown を書く

## 引き継ぎモード（`n`）

セッションの内容を新規セッションへ引き継ぐ資料を作る。全自動の要約と違い、抜け漏れを人間が判定できる。

- 上部のカバレッジバーが会話全体のうち「■ 採用済み / ◐ 保留 / □ 未採用」を 1 ラリー 1 セルで示す
- 「引き継ぎ書」は状況 / 決まったこと / 未解決 / 次にやること / 注意の 5 節。各項目の末尾に出典ラリー番号が付く
- 「保留リスト」は引き継ぎ書に入れなかったが重要かもしれない項目（要約 + 省いた理由 + 出典）
- `a` で採用（LLM が引き継ぎ書向けに再要約して適切な節へ追加）、`d` で却下、`e` で直接編集、`c` で新規セッション用プロンプトとしてコピー

## 全体要約（`m`）と自動要約

`m` の全体要約はセッションに保存され、2 回目以降は即表示になる。要約が無い状態で `m` を押すと、パネルを塞がずにバックグラウンドで生成し、完了すると自動で差し込まれる（`Esc` で閉じても裏で続き、終わると通知が出る）。`l` / `L` / `i` / `I` も同じくバックグラウンドで走り、閉じても完了まで保存される。

リポジトリの `.pi/pi-summary.json` に自動要約の設定を書ける。エージェントが 1 ラン終える（`agent_settled`）たびに閾値と成長をチェックし、必要ならバックグラウンドで全体要約を更新する。`handoff: true` にすると、同じタイミングで引き継ぎ書も増分更新する（新ラリーだけを既存の引き継ぎ書に統合し、都度完成形を保存）。

```json
{ "auto": { "enabled": true, "minRallies": 6, "growth": 3, "handoff": true } }
```

- `enabled`: 自動要約の有効化（既定 `false`）
- `minRallies`: 何ラリー以上になったら要約を始めるか（既定 6）
- `growth`: 前回の要約から何ラリー増えたら再要約するか（既定 3）
- `handoff`: 引き継ぎ書も増分更新するか（既定 `false`）

## 開発

```bash
npm test                      # 抽出とプロンプト生成のロジック
pi -e ./src/extension.ts       # 単発で試す
```

| ファイル | 役割 |
|---|---|
| `src/extension.ts` | `/summary` の登録、パネルとモード切替、LLM 呼び出し |
| `src/view.ts` | ユーザー右・AI 左の吹き出し描画 |
| `src/panel.ts` | パネルの行数上限・スクロール窓・モード遷移表 |
| `src/work.ts` | 指定した発話の直後のツール呼び出し抽出とプロンプト |
| `src/handoff.ts` | 引き継ぎ書・保留リストの生成/採用プロンプトとパース、coverage 計算 |
| `src/turns.ts` | セッションエントリ → user/assistant の発話だけ |
| `src/summarize.ts` | ラリー分割と要約プロンプト（全体・1 コメント） |
| `src/store.ts` | 保存済み要約の読み戻し（session の custom entry） |
| `src/auto.ts` | 自動要約の設定パースと発火判定 |
| `src/help.ts` | `?` のキー一覧と枠の描画 |
