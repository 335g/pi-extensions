# [H2] docs/testのみの変更はLLMスキップ

## 何を変えるか
docs / test だけの変更では LLM 分割をスキップし、決定的な単一コミットにする。

## 現状（コード根拠）
分割は常に LLM。単一コミットの heuristic は `determineType`（`src/commit-message.ts`）が docs / test / chore を判定できる。

## 実装案
`proposeCommitGroups` の手前で name-status が全て docs/test なら `fallbackSingleCommit` に倒す。

## 工数・リスク
60分
- リスク: 複数コミットに分けたい docs 変更では粒度が落ちる。
