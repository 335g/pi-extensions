# [C3] checkpointは `--no-verify`、整理コミットだけhookを通す

## 何を変えるか
checkpoint コミットは `--no-verify` で hook を飛ばし、整理コミットだけ pre-commit / commit-msg hook を通す。

## 現状（コード根拠）
`commit()` はそのまま `git commit` を叩くので、全ターンの checkpoint で hook が走る。`--no-verify` はコード中に存在しない。

## 実装案
`commit(message, { noVerify })` を追加し、`runCheckpointCommit` からは true、`commitGroups` / `fallbackSingleCommit` からは config（既定 false）で渡す。

## 工数・リスク
90分
- リスク: checkpoint が hook を通らない間に一時的に lint 違反が履歴に載る（後に消える）。
