# [D3] detached HEAD でのcheckpoint作成を警告

## 何を変えるか
detached HEAD のまま checkpoint を作ると、整理されないまま到達不能になりやすい。作成前に警告する。

## 現状（コード根拠）
`getCurrentBranch()` は detached で `null` を返す（`src/git-operations.ts`）。`runCheckpointCommit` は `null` でもそのままコミットし、trailer が欠けるだけ。警告は submodule のみ（`warnOrphanedSubmoduleHeads`）。

## 実装案
`turn_end` の checkpoint 前に `getCurrentBranch()` が null なら通知（ブロックせず警告のみ）。

## 工数・リスク
60分
- リスク: 止めると作業が進まないので警告に留めるのが妥当。
