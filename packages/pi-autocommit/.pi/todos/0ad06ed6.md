# [G4] monorepoのscope自動導出（workspaces）

## 何を変えるか
monorepo で `package.json` の workspaces から scope を自動導出する。`scope` マッピングを書かなくても `feat(web): ...` になる。

## 現状（コード根拠）
`scope` は手書きマッピングのみ（`src/config.ts` の `scope`、`src/scope-resolver.ts`）。workspaces は見ていない。

## 実装案
`loadConfig` 後に workspaces を読み、`packages/*` → `{"packages/web/**": "web"}` 相当のマッピングを生成して `config.scope` が無い時だけ使う。

## 工数・リスク
2時間
- リスク: scope が意図せず付く。`scope: {}` で明示的に切れるようにする。
