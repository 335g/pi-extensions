# [E1] `/autocommit-undo` で整理前に戻す

## 何を変えるか
`/autocommit-undo` で直近の整理を取り消し、整理前の HEAD に戻す。

## 現状（コード根拠）
整理前の HEAD は記録していない。コード中に `ORIG_HEAD` の言及はあるが（`src/commit-organizer.ts` のコメント）、コマンドは無い。

## 実装案
整理開始時に `getHead()` を `.pi/` の状態ファイルか git ref（`pi-autocommit/last-organise`）に記録し、`/autocommit-undo` で `git reset --soft <ref>`（既定）を実行。`--hard` は明示フラグのみ。

## 工数・リスク
2時間
- リスク: hard reset は作業を消す。既定は soft にして確認を挟む。
