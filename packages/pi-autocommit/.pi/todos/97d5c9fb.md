# [A5] pushされるまで自動でオフに戻す

## 何を変えるか
`/autocommit-enable false` 相当を「次に push されるまで」に限定し、push 観測後に自動で戻す。

## 現状（コード根拠）
`sessionEnable` の切り替えは手動のみ。push を観測する経路は無い（`tool_call` はブロックするか通すだけ）。

## 実装案
`tool_call` で push を許可した時にフラグを立て、`agent_end` で `getUpstreamAheadCount()` が 0 なら `setSessionEnable(true)` に戻す。
