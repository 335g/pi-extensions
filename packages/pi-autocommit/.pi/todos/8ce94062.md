# [I2] stashベースの代替パイプライン（HEADを書き換えない）

## 何を変えるか
stash ベースの代替パイプライン。checkpoint コミットを作らず stash に積み、`agent_end` で pop して分割コミットする。HEAD を書き換えない。

## 現状（コード根拠）
HEAD に checkpoint を積んで soft reset する方式が前提（ADR-0001 / ADR-0005 の trailer も前提）。

## 実装案
独立したパイプラインとして `CheckpointStore` の別実装を用意し、`turn_end` で `git stash create` + `git stash store`。整理時に `git stash pop`。
