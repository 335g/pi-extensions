# [A1] `/autocommit-pause` Nターン限定の停止

## 何を変えるか
`/autocommit-pause` を追加し、Nターン（または次の `agent_end`）だけ checkpoint 作成と整理を止める。

## 現状（コード根拠）
`enable` は boolean のセッションスナップショットのみ（`src/config.ts` の `sessionEnable` / `isSessionEnabled`）。`turn_end` と `agent_end` は `isSessionEnabled` だけを見る（`src/index.ts`）。中間状態がない。

## 実装案
`src/index.ts` のモジュールスコープに `pauseRemainingTurns` を持ち、`turn_end` 冒頭で `event.turnIndex` と比較して減算。`agent_end` も同じフラグを見る。永続化しない（セッション限定）。

## 工数・リスク
90分
- リスク: 「整理はするが checkpoint はしない」等の部分停止の扱いを決める必要。
