# [G1] グローバル設定 + プロジェクト上書き

## 何を変えるか
グローバル設定（`~/.config/pi-autocommit/config.json`）を読み、プロジェクトの `.pi/pi-autocommit.json` で上書きする。

## 現状（コード根拠）
`loadConfig(cwd)` はプロジェクトの1ファイルだけを読む（`src/config.ts`）。ユーザ共通の既定を持てない。

## 実装案
`loadConfig` の先頭で home 配下を読み、プロジェクトの JSON を shallow merge する。テストは `PI_AUTOCOMMIT_HOME` 等で分離。

## 工数・リスク
1.5時間
- リスク: 環境依存のテスト。設定の参照元が2箇所になり混乱する。
