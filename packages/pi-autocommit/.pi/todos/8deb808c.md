# [H3] `minDiffChars` で小さい差分はLLMスキップ

## 何を変えるか
`minDiffChars` を追加し、小さい差分では LLM を呼ばない。

## 現状（コード根拠）
上限（`MAX_LLM_DIFF_CHARS` 200k）はあるが下限は無い（`src/commit-prompt.ts`）。

## 実装案
`proposeCommitGroups` の先頭で `getStagedDiffSize()` が下限未満なら `[]` を返し、呼び出し側が fallback に倒れる。

- リスク: 小さな分割を期待するケースで1コミットになる。
